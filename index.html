ZERO-TRUST POLICY ENFORCEMENT

Server Security Verification

  • Default Deny: Unauthenticated or unlisted requests return 401 or 403.
  • Storage at Rest: Raw bytes in storage/*.aes are ciphertext blobs.
  • Integrity Verification: Server checks AES-GCM tag + SHA-256 digest before download. Browser re-verifies after download.
  • Transport: Local-only HTTP bound to 127.0.0.1. Not exposed to external networks.
